# Memory index

- `用户记忆/`: stable user preferences and boundaries.
- `项目/`: verified project state and facts.
- `决策/`: decisions, rationale, and consequences.
- `工作流/`: reusable procedures.
- `未闭环/`: unresolved work needing continuity.
- `agent/cases/`: reviewed reusable agent cases.

Use `memoryctl search` for retrieval. This page is a routing guide, not a manually maintained count.
