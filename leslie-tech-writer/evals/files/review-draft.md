# KV Cache 让推理快 10 倍

随着 AI 飞速发展，KV Cache 已经成为大模型推理的必备技术。我们连续
测试了三天，发现打开 KV Cache 后，所有模型的吞吐都能稳定提升 47%。

## 它缓存了什么

KV Cache 会缓存注意力层中的 Q、K、V 三组张量，因此后续所有请求都不
需要再次做矩阵计算。这就是它在任何场景都能提速的根本原因。
